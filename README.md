# Crucible

Production tracking for people who make games and 3D art. Runs on your PC, keeps your projects as files you own, needs no account and no internet.

**Website and download:** https://KillSane-sudo.github.io/crucible-releases/ · **Latest release:** [Releases](https://github.com/KillSane-sudo/crucible-releases/releases/latest)

This repository holds the compiled releases, the documentation and the issue tracker. Crucible is proprietary software; the source is not published.

## What it does

- Departments with pipelines: every asset gets its stages as a checklist.
- One work item for tasks, assets, bugs, polish and QA: estimate, logged hours, remaining, progress, planned days, dependencies, tags, screenshots, full history.
- A deterministic planner: critical path, real capacity, forecast finish day, deficit, conflicts explained. Add a department and see the cost before committing.
- Today: ranked work with reasons. Bugs with severity, location and repro. Search. Time log. Weekly report.
- Several projects side by side. Optional Claude connector (MCP) for Claude Code and the Claude desktop app.

## Install

Download the portable zip from the latest release, unzip, run `Crucible.exe`. Windows 10/11. First run: Windows SmartScreen may warn because the build is not code-signed; click **More info → Run anyway**. Verify the download against `SHA256SUMS.txt` on the release page if you like.
