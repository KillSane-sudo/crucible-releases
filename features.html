Everything Crucible does

The complete feature list for version 0.7. Every item here is in the free build. For how to use each one, read the user manual.

AreaFeatures
ProjectName, description, type, profile (Game, Asset library, Level, Minimal, Custom), engine, platform, target FPS · start date · duration 14–365 days with presets · hours per day · working days · current day and calendar date · follow the real calendar · several projects side by side, switch from the rail, delete to a trash folder
DepartmentsCatalog of about 40 · presets for game, asset library and minimal · custom departments · weights that normalise to 100 · order · production and finalization groups · park and un-park · remove with item move · recommendation from the project description with reasons · next-stage suggestion
PipelinesPer-department editable stages (add, rename, estimate, type, reorder, skip, remove, reset) · save as template · applied as an asset's checklist of child stages · stages filed into matching departments · reveal, extend and schedule stages when a department is added
Work itemsTypes task, asset, bug, design, modeling, gameplay, improvement, polish, QA, future · parent–child hierarchy with rollups · status, priority, class S–D, severity · estimate, logged, remaining, progress · planned start and end, pin, deadline, lock · dependencies · blockers · tags · checklist steps with day and required flag · location and reproduction for bugs · comments with edit history · screenshots (file or paste) with zoom · linked files and folders · full timestamped history · delete with children
Item windowOne window per item in the desktop app · resizable columns · draft-then-Save · Mark DONE with a gate · tabs Screenshot, Children, Steps, Dependencies and blockers, History · apply a pipeline template · save children as a template
PlanningDeterministic scheduler with real capacity · critical path and slack · dependencies · pins, locks and deadlines honoured · conflicts explained · replan open work from today or everything from day 1 · frozen per-day bookings · day objectives · forecast finish day, variance, deficit · recovery options · advisor rules · add-department impact preview (+hours, +days, forecast before and after)
DailyToday's focus · next-step engine with reasons and Ignore · current, next, optional · quick actions (time, comment, screenshot, child, bug) · unfinished carry-over · replan from today · logging table · quick capture into the backlog · Focus mode: one item full screen with steps and a timer, time logged in quarter hours · low-energy day: one small thing at a time · capture key
Reading & focusFonts: system, Atkinson Hyperlegible, OpenDyslexic (bundled) · text size 90–145 % · line and letter spacing · dark, warm and paper themes · calm labels (no capitals) · reduced motion · "Break it down": suggested small steps for any task, bug or asset, editable before adding
TimeTime entries with day, timestamp and note · totals by day, type, department and item · today, last 7 days, whole project or a custom range · hours-per-day chart against your capacity · corrections by negative entries
ViewsDashboard · Today · Planner · Timeline (days or weeks) · Backlog · department list, kanban with drag, and checklists, with filters and sort · Bugs · Search with eleven filters · Time log · Reports · Project Settings
ReportsWeekly report (progress, health, planned vs actual, completed, new, bugs, blockers, departments, critical path, changes, risks, recommendations) · Markdown, HTML, print to PDF, CSV, JSON · plan vs actual by department · activity stream
DataAutomatic save with a rolling backup · export and import JSON · upgrades from older versions · reset to defaults or to the sample project · templates saved with the project · one folder per project on your PC · no account, no network, no telemetry
Claude connectorOptional local MCP server for Claude Code and the Claude desktop app: list and create projects, recommend and add departments, create tasks, assets and bugs, update, set status and progress, log time, comment, run the planner, read health, next steps, today, search · every change marked with author Claude · no delete
Keyboard1–6 switch screens · / search · + add department · F focus · C capture · Esc close · Enter to save or log · paste an image · double-click a row to open it
